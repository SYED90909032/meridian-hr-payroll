# ADR-002: UAE first

Blueprint ref: D2
Status: Accepted (provisional)

## Decision
UAE pack is the first country. India follows after UAE reaches L2.

## Reason
Simpler statutory surface (no personal income tax), so the L2 process is proven first.

## Rejected alternative
India first
