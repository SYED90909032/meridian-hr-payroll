# ADR-010: One identity module

Blueprint ref: D10
Status: Accepted (provisional)

## Decision
scrypt, TOTP, sessions in our own module over vetted Node primitives. No hand-written OAuth.

## Reason
Hand-written OAuth is high risk; passkeys and OIDC are staged.

## Rejected alternative
Auth as a service
